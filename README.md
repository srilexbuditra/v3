# Srilex Buditra — Website V3

Website portfolio Full Stack Developer dengan tema dark navy + gold.

## Cara menggunakan
1. Extract ZIP.
2. Buka `index.html` di browser untuk preview.
3. Ganti nomor WhatsApp `6282136238350` di `script.js`.
4. Upload seluruh isi folder ke repository `srilexbuditra.github.io`.
5. Aktifkan GitHub Pages dari Settings → Pages → Deploy from branch → `main` / root.

## Catatan
- Foto profil sudah berada di `assets/profile.png`.
- Estimasi harga berjalan di browser tanpa backend.
- Tombol Cetak / Simpan PDF memakai dialog print browser; pilih "Save as PDF".
- Website dapat tetap online melalui GitHub Pages walaupun laptop dimatikan.
